# `vbot_navigation_section01` 环境八要素

本文根据 `VBotSection01EnvCfg`、`VBotSection01Env` 及 Section01 场景文件的当前实现，对 `vbot_navigation_section01` 强化学习环境的八个核心要素进行整理。

## 八要素总览

| 要素 | `vbot_navigation_section01` |
| --- | --- |
| 环境 | 固定的 Section01 越障导航路线。机器人从起步平台出发，依次通过崎岖高度场、约 0.28 m 的出口落差和约 15° 的上坡，最终到达 2026 平台。控制周期为 0.01 s（100 Hz）。 |
| Agent | VBot 12-DOF 四足机器人；四条腿各包含髋、大腿和小腿 3 个关节，机身为自由浮动基座。 |
| 观测 | **68 维**：机身局部线速度 3 + 陀螺仪角速度 3 + 局部重力方向 3 + 关节位置偏差 12 + 关节速度 12 + 当前动作 12 + 平滑速度指令 3 + 四足接触力 12 + 前方地形采样 8。 |
| 动作 | **12 维**连续动作，范围 `[-1, 1]`，分别控制四条腿的 12 个关节。动作乘以 0.5 rad 后叠加到默认关节角，作为 PD 位置目标；`Kp=80`、`Kd=6`，髋/大腿/小腿力矩上限分别为 17/17/34 N·m。 |
| 奖励目标 | 沿 7 个路径点持续前进并抵达终点；重点奖励线速度、角速度、朝向和目标方向速度跟踪，前进与目标距离进展，路径点达成，以及协调抬腿和地形适应；同时惩罚跌倒、异常接触、失速、姿态不稳、动作突变、关节越限及过大的速度、加速度和力矩。 |
| 初始状态 | 基座中心位置 `(0.0, -2.4, 0.5)` m，X/Y 各均匀随机 ±0.5 m；初始航向为 `π/2 ± 0.15` rad；关节使用默认站立角并叠加 ±0.03 rad 均匀噪声；所有初始速度为 0。 |
| 终止条件 | 基座指定碰撞体接触地形；机身水平线速度平方和超过 `1e8`；位姿或关节速度出现 NaN；到达全部路径点。达到 4,000 步时由时间限制截断，对应 40 s。 |
| 域随机化 | **较弱，且仅限初态随机化**：随机化出生 X/Y、初始航向和关节角。当前实现未随机化质量、惯量、摩擦、执行器增益、地形或目标点，也未在观测计算中注入噪声。 |

## 1. 环境

环境注册名为 `vbot_navigation_section01`，使用 `scene_section01.xml` 场景。任务的有效路线沿世界坐标系 Y 轴正方向展开：

1. 起步平台：约 `Y <= -1.5 m`；
2. 崎岖高度场：约 `-1.5 m < Y < 1.5 m`，最大起伏约 0.28 m；
3. 崎岖区出口落差：约位于 `Y = 1.5 m`；
4. 上坡：约 `Y = 2.0–6.9 m`，坡度约 15°，坡顶高度约 0.66 m；
5. 目标平台：约 `Y >= 6.9 m`，最终目标点为 `(0.0, 7.8)` m。

导航命令由路径点控制器在机身坐标系中生成，并通过时间常数 0.25 s 的一阶平滑处理。普通区域的 `[vx, vy, wz]` 限制为 `[-0.6, -0.35, -1.0]` 至 `[0.9, 0.35, 1.0]`；崎岖区域限制为 `[-0.25, -0.25, -0.8]` 至 `[0.45, 0.25, 0.8]`。落差和上坡衔接区域还会进一步限制前进速度。

## 2. Agent

VBot 是一个 12 自由度四足机器人，关节顺序如下：

| 腿 | 关节 |
| --- | --- |
| 右前腿 FR | `FR_hip_joint`、`FR_thigh_joint`、`FR_calf_joint` |
| 左前腿 FL | `FL_hip_joint`、`FL_thigh_joint`、`FL_calf_joint` |
| 右后腿 RR | `RR_hip_joint`、`RR_thigh_joint`、`RR_calf_joint` |
| 左后腿 RL | `RL_hip_joint`、`RL_thigh_joint`、`RL_calf_joint` |

每条腿的默认关节角为髋关节 0 rad、大腿关节 0.9 rad、小腿关节 -1.8 rad。

## 3. 观测

观测空间为 `Box(-inf, inf, (68,), float32)`，各分量按以下顺序拼接：

| 索引 | 观测项 | 维度 | 处理方式 |
| --- | --- | ---: | --- |
| 0–2 | 机身坐标系线速度 | 3 | 乘以 2.0 |
| 3–5 | 陀螺仪角速度 | 3 | 乘以 0.25 |
| 6–8 | 机身坐标系重力方向 | 3 | 单位重力向量投影 |
| 9–20 | 关节位置相对默认姿态的偏差 | 12 | 乘以 1.0 |
| 21–32 | 关节速度 | 12 | 乘以 0.05 |
| 33–44 | 当前动作 | 12 | 裁剪后的 `[-1, 1]` 动作 |
| 45–47 | 平滑速度指令 `[vx, vy, wz]` | 3 | 分别乘以 `[2.0, 2.0, 0.25]` |
| 48–59 | 四足接触力 | 12 | 每足 3 维，并旋转到机身坐标系 |
| 60–67 | 前方地形高度采样 | 8 | 在前方 0.2–1.6 m 每隔 0.2 m 采样并归一化到 `[0, 1]` |

前方地形采样对平地返回 0，对崎岖区使用 0.15 的区域标记，对上坡返回随坡度线性增长的归一化高度，对平台返回 1。

## 4. 动作

动作空间为 `Box(-1.0, 1.0, (12,), float32)`。动作按下式转换为关节控制量：

```text
目标关节角 = 默认关节角 + clip(action, -1, 1) × 0.5
关节力矩 = 80 × (目标关节角 - 当前关节角) - 6 × 当前关节速度
```

最终力矩按每条腿的髋、大腿、小腿顺序裁剪到 `±[17, 17, 34] N·m`。

## 5. 奖励目标

奖励由任务跟踪、步态塑形、地形专项塑形和正则化四类组成。当前有效权重如下。

| 类别 | 奖励项与权重 |
| --- | --- |
| 导航与跟踪 | `tracking_lin_vel: 1.2`、`tracking_ang_vel: 0.6`、`tracking_goal_vel: 2.0`、`tracking_yaw: 0.5`、`forward_progress: 1.0`、`target_progress: 1.0` |
| 目标达成 | `reach_goal: 8.0`、`reach_all_goal: 300.0` |
| 基础步态 | `feet_air_time: 1.0`、`per_leg_swing: 3.5`、`gait_symmetry: 0.2` |
| 地形专项 | `swing_foot_height: 1.5`、`drop_leg_catchup: 4.0`、`slope_leg_drive: 3.0`、`slope_front_drive: 3.0` |
| 稳定性与安全惩罚 | `termination: -10.0`、`base_contact: -10.0`、`undesired_contacts: -1.0`、`orientation: -0.5`、`lin_vel_z: -2.0`、`ang_vel_xy: -0.05`、`anti_stall: -0.8` |
| 控制正则化 | `torques: -1e-5`、`dof_vel: -1e-4`、`dof_acc: -2.5e-7`、`action_rate: -0.01`、`dof_pos_limits: -0.5` |
| 落差/坡道姿态约束 | `drop_pitch: -2.0`、`slope_pitch: -1.45`、`slope_hip: -1.0` |
| 当前禁用 | `energy: 0.0` |

其中，四足腾空时间目标为 0.55 s；崎岖区摆动足目标相对高度为 0.12 m；坡道俯仰目标使用重力在机身 X 轴上的投影 0.13，约对应 7.5° 的温和前倾。

## 6. 初始状态

每个回合重置时：

- 基座 X 坐标从 `[-0.5, 0.5] m` 均匀采样；
- 基座 Y 坐标从 `[-2.9, -1.9] m` 均匀采样；
- 基座 Z 坐标固定为 `0.5 m`；
- 航向角从 `[π/2 - 0.15, π/2 + 0.15] rad` 均匀采样；
- 12 个关节在默认站立角上叠加 `[-0.03, 0.03] rad` 均匀噪声；
- 基座和关节速度均初始化为 0；
- 路径点和最终目标保持固定。

## 7. 终止条件

以下任一条件满足时，回合立即终止：

1. 机身中部或头部指定碰撞体与场景地形接触；
2. 机身世界坐标系水平线速度平方和超过 `1e8`，作为数值溢出的保护条件；
3. 机器人位姿或关节速度出现 NaN；
4. 到达最后一个路径点，完成全部导航目标。

此外，回合达到 4,000 个控制步时被截断，即最长持续 40 s。

## 8. 域随机化

当前环境没有独立的物理域随机化流程。已经启用的随机因素仅发生在回合重置阶段，包括出生位置、初始航向和关节初始角度。

下列常见域随机化项目前均未启用：

- 机器人质量、惯量和质心；
- 地面摩擦系数和恢复系数；
- 电机强度、PD 增益和控制延迟；
- 地形尺寸、坡度和高度场；
- 路径点或目标位置；
- 观测噪声与外部扰动力。
